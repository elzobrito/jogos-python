# Pong

Jogo didático em Python com pygame-ce.

## Aula em vídeo

A aula constrói o jogo do zero em 5 partes (código em `partes/`).

## Partes da aula

- **parte-01-janela-loop** — `cd partes/parte-01-janela-loop && python3 main.py`
- **parte-02-raquetes** — `cd partes/parte-02-raquetes && python3 main.py`
- **parte-03-bola-colisao** — `cd partes/parte-03-bola-colisao && python3 main.py`
- **parte-04-placar-saque** — `cd partes/parte-04-placar-saque && python3 main.py`
- **parte-05-ia-variacao** — `cd partes/parte-05-ia-variacao && python3 main.py`

Roteiro falado da aula: [`docs/roteiro.md`](docs/roteiro.md).
